# Little-Taco-Shop
A simple HTML website for Little Taco Shop with menu, store hours, and a contact form for user feedback.

---

## Pages

1. **Home (`index.html`)**  
   - Welcome message  
   - Navigation links to other pages  
   - Image and introduction to Little Taco Shop  

2. **About / Store Hours (`LTS.html`)**  
   - Information about the shop  
   - Trivia about tacos  
   - Store opening hours  

3. **Contact (`Contact.html`)**  
   - Contact form with fields for Name, Email, and Message  
   - Big textarea for feedback  

---

## Features

- Responsive HTML structure  
- Navigation between pages  
- Form with feedback box  
- Organized layout using headings, lists, tables, and images  
- Simple design, no external CSS required  

---

## How to Run

1. Clone or download the repository.  
2. Open `index.html` in any web browser.  
3. Navigate through pages using the links in the header.  

> ⚠ Note: The contact form is static HTML and does not save feedback unless connected to a backend or script.
